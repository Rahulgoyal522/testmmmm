# NoLoginStockScanner

Fresh Android/Jetpack Compose project based on the screen/class structure observed in the supplied APK.

## Extracted structure used as reference
- Splash/Home
- Platform picker
- Scan screen
- BigBasket home/scan concepts
- Blinkit home/scan concepts
- Swiggy Instamart repository reference
- Settings
- Activation/login flow was intentionally omitted

## Important
This is a clean reimplementation skeleton, not a copy of the original APK's signing, private credentials, authentication tokens, or proprietary backend access. Live product/store data needs an authorized API or backend.

## Build
Open the folder in Android Studio and let Gradle sync. Then run the `app` configuration on an Android device/emulator.
